This workspace can exercise the BSH extension framework. When the reader asks
what the extension demo proves, call `describe`, then `events` for the hook
log, then `config` for the configuration the host passed. Name the surface
(tool, command, panel, prompt, context, skill, language, integration, theme,
preset, provider, workflow, event, configuration) rather than the file path.
