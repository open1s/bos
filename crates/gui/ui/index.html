          Per-tool policy
          
          
          
            A denied tool is never attached, so the model cannot see or call it; an
            asked tool stays but every call waits for your approval, even in a
            workspace that approves nothing else. Deny beats ask beats allow, and
            either half of a rule may be *.
          
          
          
          
            
            
          
          
          
          
          
          
          
          
            
            
            
            
          
          
          
          
          
          Resources and prompts
          
          
          
            What the connected servers publish besides tools. A resource is read
            on demand — its text never enters a prompt unless you paste it — and
            a prompt is fetched on demand the same way.

            Memory
            
            
            
              What the agent remembers across chats. A workspace may point at its own
              file; by default every workspace shares one. Written by hand here, or by
              the agent as it works.
            
            
            
            
              
              
            
            
            
            
          
            
          
            
            
            Knowledge
            
            
            
              Notes you curate — conventions, decisions, setup. The agent searches
              them on demand with knowledge_search instead of carrying them in
              every prompt, so they can be many and precise.
            
            
            
            
              
              
              
            
            
            
            
            
            
              
              
            
            
            
            
            
              
              
            
            
            
            
          
            
          
            
            
            Workspaces
            
            
            
              A workspace is a root folder, a model and a set of tools; every chat belongs to one.
            
            
            
            
            
            
              
            
            
          
            
          
            
            
            Files
              
            
            
            
            
              The active workspace on disk, one folder per click. Opening a file shows it
              in the document panel, the same panel an @ mention fills.
            
            
            
            
          
            
          
            
            
            
            
            
              
            Author a skill
            
              
            
                A skill is a folder with a SKILL.md whose body the agent reads —
                an instruction it can follow, discovered from the skills directory
                below and rebuilt into every open session when you save.
